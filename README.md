# Hourlight

A small public porch. Write at the desk. Mark a note public and it appears on the street. Every hour the room changes.

## Run

```
npm i
cp .env.example .env.local
npm run dev
```

Set `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY`.
On Vercel, add the same env vars, then deploy this repo.
